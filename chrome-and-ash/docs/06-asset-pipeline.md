# Точка подключения ассетов — путь, имена, подхват

**Назначение:** зафиксировать, куда лягут сгенерированные фоны/карты/тайлы/стенды и как интерфейс их подхватит. Это только соглашение и заглушка: арт **не генерируется**, правила **не меняются**, рендер прототипа продолжает работать на SVG/CSS.

**Следующий шаг** — подключение арт-плагина Yandex ART (`tools/yandex-art.js`), который начнёт наполнять `assets/` по этому соглашению и точечно заменять текущий рендер.

---

## 1. Структура каталога `assets/`

```
assets/
├─ manifest.json            соглашение о путях (инструменты, Node)
├─ art/                     черновики/сырьё генерации (scratch; уже есть test-tile.png)
├─ bg/                      фоны экранов и подложки
├─ tiles/                   гекс-тайлы трассы (один файл на тип)
├─ cards/
│   ├─ arsenal/             карты арсенала (22 типа)
│   ├─ upgrade/             улучшения мастерской (15)
│   └─ event/               события Пустоши (9)
├─ factions/
│   ├─ chrome/  rust/  carnival/  swarm/
│   │   └─ standee.png · glyph.png · silhouette.png · portrait.png
├─ tokens/                  жетоны статусов/ловушек + лом
└─ dice/                    кубик d4
```

Каждая пустая папка уже создана (файлы-заглушки `.gitkeep`). `assets/art/` — рабочая зона генератора, она **не** участвует в рантайм-разрешении; в рантайм попадают только файлы из структурированных папок выше.

## 2. Соглашение об именах

| Правило | Значение |
|---|---|
| Регистр | строчные латиницей, kebab-case (`engine2`, `menu-sunset`) |
| Слаг | идентификатор из `js/data.js` **без перевода и транслитерации** (`mg` → `mg.png`, а не `pulemyot.png`) |
| Кириллица/пробелы | запрещены в именах файлов |
| Один компонент | один файл; в v1 **без спрайт-листов** |
| Расширение | `.png` (вектор-исходники — только в `assets/art/`, в рантайм не ссылаются) |
| Варианты | суффикс перед расширением: `start-night.png`, `glyph-light.png` |
| Retina | `@2x` перед расширением: `start@2x.png` |
| Фоны (`bg`) | семантические слагы, не id данных: `menu-sunset`, `board-desert`, `board-night`, `card-back` |
| Фракция | папка по id + части: `standee` (стенд), `glyph` (глиф), `silhouette` (силуэт), `portrait` (портрет) |

Каталог ключей (полный список «что генерировать») — в `assets/manifest.json` и в `js/assets.js` (`CnA.assets.CATALOG`), перечисляет: 14 тайлов, 22 карты, 15 улучшений, 9 событий, 4 фракции, 9 жетонов (`mine`, `oil`, `fire`, `wreck`, `shield`, `smoke`, `burn`, `emp`, `scrap`), 4 фона, 1 кубик.

## 3. Как интерфейс подхватывает ассеты

Единая точка — `CnA.assets` из `js/assets.js` (подключён в `index.html` после `data.js`):

```js
CnA.assets.resolve('tile', n.type);            // → 'assets/tiles/start.png' | null
CnA.assets.resolve('card', h.type);            // → 'assets/cards/arsenal/mg.png'
CnA.assets.resolve('faction', 'rust', 'glyph');// → 'assets/factions/rust/glyph.png'
CnA.assets.url('bg', 'menu-sunset');           // → то же (алиас для <img>/CSS)
CnA.assets.has('card', 'mg');                  // → true (ключ в каталоге)
```

`resolve()` возвращает путь **по конвенции**, даже если файл ещё не существует. Отсутствие файла не ошибка: рендер обязан уметь откатиться (см. §4).

**Точки подключения в текущем коде** (куда следующий шаг вставит вызовы, не меняя логику):

| Место в `js/ui.js` | Что подхватит | Текущий рендер (фолбэк) |
|---|---|---|
| `renderBoard()` → отрисовка гекса (`hexPoints` + `COMIC_FILL`) | `tile:<type>` | плоская SVG-заливка `COMIC_FILL[n.type]` |
| `renderBoard()` → жетоны (`tokenOffsets`) | `token:<type>` | SVG-фигуры (мина/масло/огонь/обломки) |
| `carFigure()` | `faction:<id>:standee` | мультяшная SVG-фигурка-стойка |
| `renderMenu()` → карточка фракции | `faction:<id>:portrait` / `glyph` | текст + глиф `f.glyph` |
| `renderHand()`/карты мастерской | `card:`/`upgrade:`/`event:` | DOM-карточка с `CARD_ICON` |
| фон меню/игрового экрана (`menu-sky`, `.screen`) | `bg:*` | CSS-градиенты `css/style.css` |

## 4. Фолбэк-контракт (обязателен)

Пока файла нет или он не загрузился, рендер **не должен** ломать игру и **не должен** менять игровую информацию. Следующий шаг добавляет арт строго по схеме «попробуй загрузить → при ошибке оставайся на текущем SVG/CSS». Числа, фазы, цели и вся логика (`engine.js`, `data.js`, `track.js`) в этом процессе не трогаются.

## 5. Два источника истины

- **Рантайм** — `js/assets.js` (`CnA.assets`). Браузер открывает `index.html` с диска (`file://`), поэтому `fetch('assets/manifest.json')` не используется: конвенция вшита в JS.
- **Инструменты** — `assets/manifest.json`. Читается Node-инструментами следующего шага (арт-плагин, генератор списка «что сгенерировать»).

Они обязаны совпадать; расхождение ловит `node tests/assets.js` (сверяет манифест ↔ `assets.js` ↔ данные `data.js`).

## 6. Связь с брифом «Закат в Пустоши»

Имена и пути здесь — только каркас. Содержание файлов (палитра-токены, размеры, контраст, неон-привилегия Карнавала, ночная сторона) регулирует `docs/05-art-brief-sunset-readability.md` — это контент-контракт для художника и критерии приёмки. Нарушение неон-привилегии или пары «белый текст на латуни/полымя/неоне» остаётся блокером приёмки.

## 7. Сборка `dist/`: арт рядом с одностраничником

`build.mjs` инлайнит CSS и JS в `dist/chrome-and-ash.html`, а затем копирует `assets/` → `dist/assets/`:

- копируются **только `.png`** — рантайм-арт (фоны, портреты фракций, рубашки карт);
- `assets/art/` (scratch-зона генератора) **не** копируется;
- `.gitkeep` (заглушки пустых папок) и `manifest.json` (инструментальный, читается только Node) **не** копируются.

Пути в рантайме остаются относительными `assets/…`: `CnA.assets` возвращает `assets/…` и одинаково работает из корня исходника и из `dist/`. Единственная правка при инлайне — `build.mjs` переписывает CSS-пути `url('../assets/…')` → `url('assets/…')`: в исходнике `css/style.css` лежит в подпапке `css/`, откуда `../assets/…` верен, а после инлайна базовый URL документа = `dist/`, и `../assets/…` указывал бы мимо `dist/assets/`.

Раскладка собранного дистрибутива:

```
dist/
├─ chrome-and-ash.html    CSS/JS инлайн, без внешних ссылок
└─ assets/                арт рядом (bg/, factions/…/portrait.png)
```

`index.html` из исходника работает как раньше: `css/style.css` подключается отдельно, и его `../assets/…` указывает на `assets/` исходника.

## 8. Проверка

```bash
node tests/assets.js    # соглашение о путях: manifest ↔ assets.js ↔ data.js
node build.mjs          # сборка dist/ не должна сломаться от добавления assets.js
```
