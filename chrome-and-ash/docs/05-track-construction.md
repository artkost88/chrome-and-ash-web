# Генератор, валидатор и конструктор трасс

**Статус:** генератор/валидатор и параметрический конструктор v1 в `chrome-and-ash-web/js/`.
**Архетипы:** клубное кольцо, пыльная подкова, змея.
**Контракт:** `TrackSpec` → `compileTrack` → runtime track, совместимый с текущим рендером и движком.

---

## 1. Правила уровня трассы

1. Один старт-финиш, одно направление движения.
2. У обычного тайла один вход и один выход; развилка имеет два выхода, слияние — два входа.
3. Нет тупиков: каждая ветка возвращается в основной круг.
4. Все дорожные тайлы достижимы из старта и ведут к финишу.
5. Развилка и слияние — парные; срез экономит 1–2 тайла и имеет риск, пит — не срез.
6. Дороги на одном уровне не пересекаются; путепровод — отдельный уровень (не в первой версии).
7. Стартовая решётка — 2×2 на двух тайлах; без опасностей, трамплина, пит-входа и развилки.
8. Длина основного круга — 24–36 тайлов; стартовая зона — 4–6 чистых тайлов; КП — в середине круга.

## 2. Архетипы

| Архетип | Длина | Пит | Срез | Характер |
|---|---:|---|---|---|
| `club` — Клубное кольцо | 24 | тайл пита | нет | обучение, широкие повороты, меньше опасностей |
| `horseshoe` — Пыльная подкова | 36 | ветка 3 тайла | нет | шикана, тоннель, мост, шпилька, пит |
| `snake` — Змея | 31 | нет | 1 | волнистая техничная трасса, шиканы и платный срез |

Архетип задаёт бюджет сегментов, стартовую зону, число опасностей (2–5), наличие пита/среза и позицию КП.

## 3. TrackSpec

```js
{
  schemaVersion: 1,
  id: 'snake-1a2b3c',
  name: 'Змея',
  archetype: 'snake',
  seed: 12345,
  size: 30,              // число дорожных тайлов
  hexSize: 34,           // размер гекса на экране
  layout: 'polar' | 'axial' | 'snake',
  levels: 1,
  startNode: 0,
  grid: [29, 29, 28, 28],
  nodes: [{ id, q, r, x, y, type, next: [], checkpoint, pitLane, level }],
  pit: { entry, exit, nodes: [] } | null,
  shortcut: { entry, exit, nodes: [], type } | null,
  checkpoints: [0, 15],
  decor: [{ q, r, type }]
}
```

`compileTrack` строит `nodes.next/prev`, `edges`, `main`, `pit`, `distFromStart`, `distToFinish`, координаты и поля, которые ожидает `renderBoard`/`engine`.

## 4. Валидатор

`validateTrackSpec(spec)` возвращает `{ ok, issues: [{ code, message, nodeId? }] }`.

| Код | Что проверяется |
|---|---|
| `E_SCHEMA` | версия и обязательные поля |
| `E_LENGTH` | 24–36 тайлов |
| `E_START_COUNT` | ровно один старт |
| `E_GRID` | 4 слота, 2 тайла, чистые |
| `E_DEGREE` | 1 вход/1 выход; развилки/слияния |
| `E_DEAD_END` | нет тупиков |
| `E_REACHABILITY` | все дорожные узлы достижимы |
| `E_HAZARD_RUN` | не более 2 опасностей подряд |
| `E_HAZARD_ZONE` | опасность не на старте/решётке/КП |
| `E_RAMP_ZONE` | трамплин не на старте/решётке/КП |
| `E_CHECKPOINT` | 1 КП, 25–65% круга |
| `E_PIT` | вход/выход, длина ветки |
| `E_SHORTCUT` | вход/выход, экономия 1–2 тайла |
| `E_DUPLICATE_COORD` | две дороги не в одной клетке |

`validateTrack(track)` — legacy-обёртка для runtime-трассы: возвращает массив строк, чтобы не ломать board UI.

## 5. Генерация

```js
generateTrackSpec(seed, { archetype, size })
  → buildSkeleton(...)
  → assignSegmentTypes(...)
  → addPit/addShortcut(...)
  → placeCheckpoints/placeDecor(...)
  → validateTrackSpec(...)
  → при ошибке повтор (до 64 раз) или детерминированный fallback
```

- `club`: осевое кольцо `hexRing(4)`, 24 тайла; типы назначаются слотами; стартовая зона и решётка защищены.
- `horseshoe`: осевой шаблон подковы, 36 тайлов; варьируются опасности/слоты, пит фиксирован.
- `snake`: осевой стадион с шиканами и срезом, 31 тайл; срез имеет риск.
- `club/snake` используют внутренний shortcut-узел; `horseshoe` — пит-ветку.
- Сид определяет раскладку типов; геометрия детерминирована.
- `hazardBudget: [min,max]` (конструктор) переопределяет число опасностей на основной петле; старт, решётка, КП, пит и срез защищены.

## 6. Интеграция

- `createGame({ trackArchetype, trackSize, trackSpec, trackName, ... })`.
- Free race: выбор архетипа на экране фракции; `trackArchetype` сохраняется в `SaveState`.
- Daily/PvP пока используют подкову (`mosaic/36`); серверная миграция архетипа — отдельный этап.
- Board: `track-gen.js` подключён до `track.js`; `#opt-track` даёт подкову/кольцо/змею.
- Конструктор v1: `track-editor.js` + `track-editor-ui.js`; localStorage `cna.customTracks.v1`, JSON-экспорт/импорт; тест-драйв через `trackSpec`.

## 7. Конструктор трасс v1

- Вход: гараж → «КОНСТРУКТОР ТРАСС».
- Параметры v1: архетип, seed, бюджет опасностей, имя.
- Геометрия, длина, пит и срез фиксируются архетипом; ручная правка — этап B.
- Хранение: localStorage `cna.customTracks.v1`, максимум 40, импорт JSON ≤100 КБ.
- Экспорт: `{kind:"cna-track", version:1, track:{...}}`.
- Тест-драйв: `createGame({trackSpec, trackName, trackArchetype:"custom"})`.
- Серверная библиотека и share-ссылки не входят в v1.

## 8. Приёмка

- 100 сидов × 3 архетипа проходят валидатор.
- Конструктор: бюджеты `[0,0]/[2,2]/[5,5]` на 20 сидах × 3 архетипа проходят валидатор.
- Генерация детерминирована, <50 мс на трассу.
- Free race: выбор, старт, сохранение, продолжение.
- 200–500 AI-гонок на архетип без исключений; метрики: 2+ финишёра >30%, ранние смерти <10–13%, разброс фракций <12 п.п.
- Рендер не падает; старт 2×2; пит/срез читаются.
- Конструктор: сохранение/загрузка после reload, экспорт/импорт JSON, тест-драйв с тем же именем трассы.
